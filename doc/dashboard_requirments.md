Objective: Hospital event logs ni chusi process ela jarugutundo chupinche dashboard plan cheyali.

Users:
1. Project reviewers - short overview kavali
2. Process analysts - activity sequences chudali
3. Hospital stakeholders - aggregated results

Questions dashboard answer cheyali:
- Total Cases enni? (328 candidate IDs)
- Total Events enni? (2222 candidate events)
- Most frequent activity edi?

Required Fields:
- Case ID, Activity, Timestamp, End Timestamp (if available)

Filters: Activity, Date, Authorized Case ID

Limitations: ID meaning confirm cheyali, time gap = waiting time kaadu, missing data undi.
