# CareFlow - Project Introduction & Scope

## Introduction
Hospitals handle many patients daily. Each patient goes through multiple steps like registration, triage, consultation, lab test, pharmacy. Sometimes patients wait long time in between steps. Our project CareFlow tries to find where the delay happens using process mining concept.

We got this idea because in our college hospital visit we observed long queues at lab and pharmacy.

## Problem Statement
- No clear visibility of patient journey
- Admin does not know which department causes delay
- Existing hospital system only shows data, not process flow

## Scope - What we will do in this project
In Scope:
1. Collect or use open source event log for clinical pathway
2. Clean the data and find process flow
3. Calculate KPIs mentioned in kpi_definitions.md
4. Build a simple dashboard to visualize bottlenecks
5. Give suggestions to reduce waiting time

Out of Scope (for now):
1. We will NOT build full hospital management system
2. We will NOT handle real-time live data in Sprint 1
3. We will NOT predict diseases, only analyze flow
4. Mobile app is out of scope

## Expected Outcome by Final Sprint
- A working dashboard that shows patient flow and bottlenecks
- Report with process improvement suggestions
- GitHub repo with proper documentation (this docs folder is start)
